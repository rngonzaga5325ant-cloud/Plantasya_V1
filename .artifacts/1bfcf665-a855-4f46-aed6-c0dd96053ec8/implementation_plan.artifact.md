# Fix missing TensorFlow Lite Metadata dependency

The build is failing because the `org.tensorflow.lite.support.metadata` package is missing. This package is required by the code generated by Android Studio's ML Model Binding feature when a `.tflite` model is used. The `MetadataExtractor` class resides in the `tensorflow-lite-metadata` library, which needs to be explicitly added to the project dependencies.

## Proposed Changes

### Build Configuration

#### [MODIFY] [libs.versions.toml](file:///C:/Users/PC/AndroidStudioProjects/Plantasya_V1/gradle/libs.versions.toml)
- Add a new library entry for `tensorflow-lite-metadata` using the existing `tensorflowLiteSupport` version (0.4.4).

#### [MODIFY] [build.gradle.kts (app)](file:///C:/Users/PC/AndroidStudioProjects/Plantasya_V1/app/build.gradle.kts)
- Add `implementation(libs.tensorflow.lite.metadata)` to the dependencies block.
